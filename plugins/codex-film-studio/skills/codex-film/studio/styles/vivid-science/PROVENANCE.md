# Provenance

The visual grammar was independently studied from saturated vector science
animation, including Kurzgesagt's public work. These notes and tools contain no
reference footage, branded character, narration, melody or traced scene.

Lemo-Opuscar's public directing and technique guides informed the distinction
between attractive frames, choreography, sound and verified delivery. Its
production code and style implementations were not copied into this toolkit.
See https://github.com/lemomo-ai/lemo-opuscar .

Generic tools and drawing primitives here are newly authored. Dependencies retain
their own licences. Nunito is licensed under SIL OFL; the retained licence is
inside the starter fonts directory. Reference licences do not grant permission
to redistribute reference films. Keep those files with the private production
analysis only when permitted.

The independent style page uses an original generic vector study and the Jost
font under SIL OFL 1.1; its full licence is retained in `showcase/fonts/`.
The page study is separate from the released film’s characters and scenes.
