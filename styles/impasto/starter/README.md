# Author an impasto film

Install dependencies using npm ci. The local compiler uses the installed Playwright Chromium binary. Install it with npx playwright-core install chromium if needed, or set IMPASTO_CHROMIUM to a compatible offline compiler executable. Rendering uses a fresh temporary profile. Run npm run proof for a material swatch. Edit src/film.js. npm run still -- 12 shot.png inspects second 12. npm run picture produces picture.h264. Use scripts/ffmpeg_serial.py to mux this 24 fps Annex B stream with your PCM stereo mix, with -r 24 before the video input, -c:v copy and -c:a aac. Keep the WAVs and source composition.

Export duration in seconds and async function setup(stage) returning function frame(t). Coordinate system 1280×720. Renderer clears before and lights after frame(t). Stage.plate(w,h,draw,options) prepares a reusable surface. Its draw callback receives Ref with fill(pathFn,css,props), line(pathFn,css,width,props) and text(string,x,y,font,css,props). Path callbacks accept a Canvas2D context in local coordinates. Polygon, ellipse, rectangle, curve, gradient and matrix helpers are exported by src/stage.js. Use transparent plates for objects and pivoted limbs. Stage.paint(plate,{cam,M,t,grey,reveal,revDur,revC,alpha,run,appear,appDur}) draws. grey is 0–1; reveal:1e6 keeps the plate grey, reveal:-1e6 paints in full colour. revC:[x,y,speed] and a matching plate rev:(x,y)=>delay spread a reveal. Use stage.marks(strokes,opts) for procedural action: import Strokes and hex from engine/impasto.js. Stage.light sets per-frame post overrides. The engine's plate and stroke APIs are local in engine/. Set plate opts R (radius array), seed, scale, T (edge threshold), rev and app. Use a stable seed and a smaller ref scale for distant fields.

src/stage.js exports poly([[x,y],...]), rect(x,y,w,h), oval(x,y,rx,ry,angle=0), path(fn), grad(x0,y0,x1,y1,[[position,css],...]), transform(x,y,scale=1,angle=0,anchorX=0,anchorY=0,scaleY=scale), ease(u), mix(a,b,u), hash(seed). stage.paint places the plate at its native origin unless M is supplied. Camera defaults to {x:640,y:360,zoom:1,rot:0}. Camera zooms may reveal the plate boundary: keep scene edges outside the aperture.

A film needs an authored soundtrack, original narration when requested, and final-file checks. Use any available voice integration with a measured and retained WAV. For several shots, keep cue starts in one data file and author actions at the actual beats. All external FFmpeg invocations including probes using the ffmpeg executable must use the shared serial runner. ffprobe itself can inspect metadata independently.

For a requested frame-level reference comparison, scripts/compare_frames.py scan INPUT.mp4 measurements.csv records brightness, contrast, accent coverage, fine and broad relief, mark directionality and movement on every decoded frame. Run it on each film. A roles JSON defines "reference" as {role: [[start,end],...]} and "output" as ordered [start,role] pairs starting at zero, in seconds. Then use compare REF.csv FILM.csv ROLES.json OUTPUT. The two CSVs pair every output and reference frame in both directions; the reported component differences are diagnostics. Visually reopen the largest differences, cuts and performance contacts.

The project's Impasto-specific commands above own the picture build. The shared tools/runtime directory supplies optional cross-style utilities.

For motion and sound revisions, retain the previous encode. Spot camera moves, physical contacts, ambience, score changes and narration on the same film clock. Archive the accepted generated track, prompt, exact source/film edit times and field-recording credits. Keep separate voice, music, effects and final-mix stems. The film showcase should name how its music was made and provide working, separately labelled auditions for the generated take and edited soundtrack. See STYLE.md for native-speed comparison and hold diagnostics.

For human actions and physical props, use [Physical continuity](PHYSICAL-CONTINUITY.md), the planar helpers in src/kinematics.js and the pose-adapter contract in STYLE.md. Record the shot and frame of a broken grip or unsupported pose and test that same moment in the encoded revision.
