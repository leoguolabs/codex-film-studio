# Vermilion Paper Cut · 朱红窗花剪纸

An independent cut-paper animation kit for an original English story. It provides opaque paper layers, genuine perforations, stepped jointed movement, creased flaps, cut captions and timeline-matched sound.

Create a working copy with `python3 scripts/new_film.py NAME --style papercut-red`. The [starter](starter/) explains how to author an editable film. Read [STYLE.md](STYLE.md) for the visual and sound direction.

[Paper Holds Light · 纸里有光](https://leoguolabs.github.io/codex-film-studio/styles/papercut-red/showcase/index.html) is a bilingual screening room. Scroll through actual frames of a scissor cut, a fold opening, a backlit arrow and a paper turn. Watch both original films or hear the Gemini recordings, the edited scores and paper Foley separately.
