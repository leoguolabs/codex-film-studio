# Drawing a colored-pencil film

Install with npm ci. The offline compiler uses WebGL2 and WebCodecs in an isolated Playwright Chromium process. If Chromium is missing, run npx playwright-core install chromium. A local installation can be selected with PENCIL_CHROMIUM. Run npm run proof to draw a material sphere.

Author src/film.js. Export duration in seconds and setup(E), which builds the world once and returns a deterministic function of time. That function returns {main, inset?, iris?, caption?, label?, title?}. The field main is a perspective view. E.view(x,y,z,anchor,focus,hide) centers a point on the z=0 plane with a fixed downward pitch. The anchor [x,y,z] stays constant within each shot. focus is a material-ID to pressure map; hide is a list of IDs. E.lens(wide,detail,world,t,start,duration,closing=false) creates the main, inset and iris fields. world is a three-element coordinate or Vector3. Put the same visible physical landmark under both scales.

Use E.mesh(threeGeometry,{id,kind,dir,color},optionalMatrix) for a single mesh. IDs range from 1 to 31; 0 is sky. Color is E.rgb(hex). Material kinds are plain (0), soil (1), bark (2), leaves (3), turf (4), mottled stone (5) and unshaded (6). dir selects fixed, longitudinal or curved hatching (0, 1, 2). E.THREE and E.V(x,y,z) are available. For repeated shapes, use E.Builder and E.append(builder,geometry,matrix,colorFunction,tangent). E.tube(builder,points,radii,sides,colorFunction,radiusFactor,occlusion,revealTime) takes a Vector3 array, per-point radii and an RGB callback. The last three callbacks are optional. E.add(builder.geo(),E.mat(options)) submits the batch. Set mesh.userData.active=false to hide a mesh. Objects that grow can use a material with disc:1 and vertex reveal times. Reserve IDs 6–10 for ground horizons and 11–13,15,18,20 for growing forms. Bake nonuniform scaling into geometry for correct normals.

Caption takes {text,start}, label takes {text,x,y,at,start,size?}, title takes {text,x,y,start,size?}. Coordinates for lettering use a 1920×1080 page with y pointing down. A label's at is a 3D point. Select each text event only during its intended interval. Fit subtitle text with the measured voice, and clear the bottom-left corner of key detail.

Render a still with npm run still -- 10 still.png. npm run picture creates picture.h264 (24 fps, 1920×1080). For a short motion proof set PENCIL_FRAME_LIMIT to a frame count and PENCIL_PICTURE to a separate filename. Mix accepted speech plus your score and foley to a WAV on the same timeline, then run python3 scripts/ffmpeg_serial.py -r 24 -i picture.h264 -i mix.wav -c:v copy -c:a aac -b:a 256k -movflags +faststart film.mp4. Keep generated media and new story geometry together in your external project.

For different coordinate systems at two scales, pass a separate detailWorld as the eighth argument to E.lens. The inset centers that same feature on the outer ring. A view may specify pitch in radians; preserve its value throughout a continuous move and apply the same orientation to the stroke anchor.

For a commissioned reference comparison, scripts/compare_pencil.py can scan the reference and film into separate CSV files. It reads every decoded frame and twelve native-resolution grain patches per frame. Its compare command takes the two CSVs, a shot-role JSON, and an output directory. The JSON has a reference object mapping each role to disjoint [start,end) ranges in seconds and an output array of [start,role] shot entries from time zero. The program checks coverage both ways and saves normalized shot-phase pairs as well as nearest-feature matches. Open actual frames to judge material, motion and physical sense. The comparison requires NumPy, SciPy and OpenCV.
