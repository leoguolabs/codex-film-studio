# Author a risograph film

The sheet is 1920 × 1080, 24 fps. Copy this whole kit to a working directory. Set film.js, content/narration.json and content/score.json. Install Node dependencies with npm ci. Install Python dependencies from requirements.txt. For rendering install the matching Chromium with npx playwright-core install chromium or point RISO_CHROMIUM at a local Chromium binary. The browser process is an offline canvas renderer. The sound generation accepts local Kokoro v1.0 model and voice bank files.

In film.js export film, drawScene(t,poseTime) and vignette(t). Set film.title (uppercase), subtitle, credit, duration, ordered cuts in seconds, three plate arrival times, kicks as [seconds,amplitudePixels], titleWindow as [start,end], optional drift as [start,end], and end as the start of the closing card. The framing module handles title, subtitles, closing type, grain, registration and roller. Author the action, background variation, physical sheet reveal and tiny closing performance. Draw using the live g context and primitives in engine/draw.js. Each colour array holds blue, yellow and pink densities from zero to one. Black on the separation canvas prints bare paper. Use layer(fn,4) for the main figure and over(fn) for an ink laid across existing forms. Restore transforms before leaving a shot. Align a new shot with a musical or physical event.

Each narration line has id, at in seconds, text and optional caption (an array of one or two lines with identical wording). Use python scripts/voice.py --models MODEL_DIRECTORY to generate audio/takes, content/cues.json and media/English.srt. Set voice, lang, speed, and duration in narration.json. Reuse unchanged takes by omitting --models when rebuilding. Supply chords in score.json as [bassMIDI,chordMIDI1,chordMIDI2,...] per bar and melody as four MIDI notes per bar with zero for a rest. Set arrivals to the yellow and pink times and choose effects entries [seconds,kind] from drum, paper, bell and clack. Optionally add your own Foley as part of the mix. The script writes the stereo mix and three stems.

Run python scripts/sound.py, then npm run render -- frames and python scripts/encode.py frames "Film.mp4". The encoder waits for any active FFmpeg process. Preview with npm run render -- proof 0,48,120 using frame numbers from your own timeline. Use a fresh folder when the edit changes duration. Keep film.js, artwork, timings, sounds and the accepted export. Regenerable frame caches may live in temporary storage.

The encoder measures the mix, masters it to a nominal −14 LUFS with a true-peak ceiling and saves audio/master.wav before muxing. Check the encoded AAC loudness and speech. For a comparison install the packages in requirements-review.txt, run scripts/frame_audit.py scan on each MP4, then run scripts/compare_prints.py with the two video paths, their scan directories, a comparison directory and a role map. The JSON role map is an ordered list of {"name":"shot function","ref":seconds,"new":seconds} objects beginning at zero, ending at both runtimes and sharing the same editorial function between boundaries. A shift in colour coverage or motion needs a visual check. View the paired sheets and any extra reference frames, and inspect doubtful moments at native size. Keep the actual first export before revising.
