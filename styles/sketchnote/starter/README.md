# Make an English sketchnote

The sheet is 1920 × 1080 units. Work in a copy of this kit, using Node 20+ and Python 3.11 with the packages in requirements.txt. Run npm ci and npm run proof. FFmpeg and ffprobe are required for delivery. For new voice synthesis set KOKORO_MODELS to the folder containing kokoro-v1.0.onnx and voices-v1.0.bin from the Kokoro ONNX release. Rebuilds from retained takes do not need a model.

1. Write content/narration.json. Each line has an id and English text. Optional at sets the earliest start, gap sets a pause after the take, caption overrides display wording. Set tail for the closing poster hold. Run python scripts/sound.py voice. content/cues.json contains c0 (voice start), end (voice end), c1 (slip end), text and the retained take. content/clock.json gives the exact film duration.
2. In src/film.mjs export an object with build(page,cues). Register drawings in back-to-front order, giving each stroke absolute start time and duration in seconds. Return {camera} or {camera,follow}. Camera keys use [seconds,centreX,centreY,zoom,optionalEase]; 'whip' is available. Two keys at the same time cut to a new centre. Normal wide is [t,960,540,1]. follow accepts {at,duration,points,zoom,offsetY}; resample(points,3) before handing in the moving outline. At a normal close view (around 2×), use panel widths of 350–430 units, object contours of 90–240 units and notes of 22–34 units. A detail at about 10–15× needs its own fine lines (w .3–.8, amp .1) and small type. Stage visible events from each cue's c0.
3. Build drawing geometry with line(x1,y1,x2,y2), ell(cx,cy,rx,ry,startAngle=0,endAngle=TAU,segments=90,rotation=0), bez(p0,p1,p2,p3), rrect(x,y,width,height,radius), shift(points,dx,dy) and arrays of [x,y]. INK_(points,{w,amp,closed,col,passes},at,duration) draws the contour. MRK([outer,optionalCutout],{col,w,ang,amp},at,duration) shades inside it. FILL(points,at) lays paper beneath a foreground shape. MST(points,{w,col},at,duration) draws a marker stripe. Use INK, INK2, GRY, GRY2, GRYD, YEL, YELD from page; an optional film.palette.acc array changes the accent RGB. TXT(text,x,baselineY,size,{f:'KB' or 'PH',align:'left' or 'center',col,rot},at,duration) writes the label. Set amp and nib width explicitly when working small.
4. Structural helpers include box(x,y,w,h,at,duration), ribbon(cx,cy,w,h,label,fontSize,at,{fill,td,d}), fatArrow(x1,y,x2,at), inkArrow(points,{w,head},at,duration), dropShadow(points,dx,dy,at,duration) and sparks(cx,cy,innerRadius,outerRadius,angles,at). Set ribbon fill to null for the white main title and add a narrow accent under its keyword. Use fresh drawings for the subject.
5. Author content/score.json. Each entry in sections supplies at, until, chord (a low MIDI bass pitch then three or more chord tones) and optional bpm. Times may be seconds or a narration cue id. Optional notes use [cueOrSeconds,offsetSeconds,midiPitch,"wood"|"bell"|"bass"|"harp",duration,gain,pan]. Compose the rests, chords and coda around the actual narration. Run npm run events, then python scripts/sound.py mix to make 48 kHz voice, music, pen and stereo mix WAVs. The engine derives contact sound from the actual drawing events.
6. Run npm run still -- SECONDS media/proof-of-shot.jpg. Inspect the opening clue, detail, comparison and full poster. npm run frames accepts an optional half-open frame interval. npm run encode -- media/film.mp4 waits for existing FFmpeg jobs, encodes the JPEG sequence and mix, and checks decoded stream metadata. The full npm run build command uses the existing voice clock. Keep the drawing source, cues, takes, stems and captions with the MP4.

For a comparison, install OpenCV and Pillow alongside NumPy. Run python scripts/compare.py scan MOVIE OUTDIR to decode every frame, its presentation timestamp, and its paper, ink, grey marker, accent and motion measurements. For two films, create a JSON list with role, reference and output fields; each interval is a pair of half-open frame numbers. Cover the entire timeline on each side. Run python scripts/compare.py pair REFERENCE_SCAN OUTPUT_SCAN ROLES_JSON REPORT_DIR. Inspect the changing forms at the largest camera scale as well as the role-matched transfers. The CSV files preserve the measurements in both directions.
