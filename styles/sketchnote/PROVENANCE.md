# Drawing tools

The fineliner, marker, ribbon, hand-lettering masks, world paper and camera interpolation adapt MIT-licensed drawing code by Lemomo (LemoLab), revision 439b98af08b04400f8fd8a8dd19cd773c0c96532. This version runs in Node, takes new artwork, directs its camera from authored keys, includes an English caption slip and emits timing for the sound engine. The license is in engine/LICENSE-MIT.txt in each working copy. Kalam Bold and Patrick Hand are distributed under their accompanying SIL Open Font Licenses.
