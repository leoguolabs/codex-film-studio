# Xuan Ink Film
Author in 1920 × 1080 world coordinates at 24 fps. In film.js export setup() to cache plates and draw(A,B,t) to stage each frame in seconds. Each sheet exposes A.cw, A.cd and A.cc for wet black, dry black and colour. A.ink groups the same three contexts. Return compositor options {bleed,rim,paper,rev,trans}. The paper tuple is [offsetX,offsetY,scale]. rev:[cx,cy,radius,1] reveals wet/dry ink on A, and trans:[cx,cy,radius,1] uncovers the incoming B from A. Both use pixel coordinates. Cache static mountainLayer(), cun(), reed() or your own marks on plate() in setup; use pose() to transform all pens together. engine/studio.js provides a brush stroke, captions, seal and handscroll mount. engine/ink.js supports seeded pressure profiles, wet and split brush, blot() and mass(). Draw a new subject in film.js, including its largest close-up and the changing pose. Retain the direction of movement and the origin of any reflection.

Put duration and lines in content/narration.json. Each line has id, at (seconds), text, caption (array of English lines, whose words equal text), and pos [x,y,size]. To move inscriptions across a cut export captionPosition(index,t) returning that tuple. Use size 42–48 for inscriptions. Keep caption boxes clear of ink in the actual picture. Generate voice before pictures. Set the scrubbed film to end after the last spoken line.

Install npm ci and Python packages in requirements.txt; for generating new speech also install requirements-voice.txt and use Kokoro v1.0 ONNX plus voices-v1.0.bin. Run python scripts/voice.py --models MODEL_DIRECTORY once, then python scripts/voice.py reuses accepted WAVs. Edit content/sound.json. Notes are [at,MIDI,duration,gain,instrument,pan], with instrument string, harmonic or flute. Effects are [at,kind,duration,gain,pan] with drop, brush, splash, wind, wash, tap, drum or seal. Silences are [start,end] in seconds. Example gain ranges are .10–.25 for plucks, .04–.10 for flute and .05–.25 for Foley. Compose each phrase around the on-screen gesture. Run python scripts/mix.py for stereo stems and mix.

Use npm run proof for a brush swatch. Render a topic still with npm run still -- SECONDS FILE.png and the whole picture with npm run picture. The offscreen WebGL compiler uses an isolated Chromium for Testing installation (INK_CHROMIUM overrides its path). Install a matching Chromium with npx playwright-core install chromium when needed. Run python scripts/ffmpeg_serial.py -- -v error -y -fflags +genpts -r 24 -i picture.h264 -i audio/mix.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 256k -movflags +faststart media/film.mp4. The runner waits for the shared lock and any existing FFmpeg process. Voice generation creates media/ and the English SRT. Keep the encoded MP4, source, accepted audio and review together.

For two films at 24 fps, run python scripts/scan_frames.py scan FILE.mp4 AUDIT for each; install opencv-python-headless and Pillow for this step. Then run python scripts/compare_ink.py REF_AUDIT FILM_AUDIT ROLES.json OUTPUT. Supply an exhaustive list of [role,refStartSeconds,refEndSeconds,filmStartSeconds,filmEndSeconds] with contiguous half-open boundaries, chosen after checking the actual shots. The paired sheets use the reference on top and the new drawing below. The CSVs include every frame and its low-level diagnostics in both directions. Inspect the drawings, sounds and register changes before accepting the film.

For a delivery with a loudness target, run python scripts/master.py --lufs TARGET --range LRA --peak TRUE_PEAK after mixing. Use audio/master.wav in the mux, then measure the encoded AAC. The original mix and stems remain available. Match the measured listening level of a named reference when requested.

Pass mountPaper: [screenX, screenY, width, height] with a moving scroll window so desk texture stays fixed outside the sheet. In an extreme close-up of a held drawing, sample the camera target from the exact pose on screen. Track whiskers or other secondary motions separately.

For a decisive brush gesture or a score and foley revision, use [Directing a loaded-brush gesture](GESTURE-AND-SOUND.md) for the pressure stroke, recorded-material editor and release-aligned frame comparison.
