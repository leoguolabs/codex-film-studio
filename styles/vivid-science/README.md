# Vivid Science

A reusable guide and material toolkit for expressive, saturated vector science
animation. Read [STYLE.md](STYLE.md) for drawing, motion, sound and review rules.
[The starter](starter/) includes an executable renderer for shaded vector bodies and deforming ribbons,
an abstract material probe, empty input contracts and frame-analysis tools. It does not render a
complete story automatically and contains no example-production assets.

Create an independent working copy with the library's normal project command,
then author new scenes and connect them to actual narration timings. The
production may use another rendering stack if appropriate; the visual and review
requirements apply to the delivered result.
