# Draw a Marker on Paper film

Install the Node dependencies with `npm ci`. The sound scripts use Python 3.11 and the modules in requirements.txt. Run `npm run proof` to see the material. For new speech supply a Kokoro v1.0 model directory with kokoro-v1.0.onnx and voices-v1.0.bin, or import recordings using the timing contract below. The acoustic instrument samples and both English font weights travel with this kit.

Write content/narration.json first. The top level contains duration (seconds), voice, speed, lang and lines. Each line has a unique id, whole-film start time at, English text and optional caption (one or two strings whose joined text equals text). An optional speak string controls pronunciation. Run `python scripts/voice.py --models MODEL_DIR`; after the first recording, `python scripts/voice.py` rebuilds timing from retained takes. Measured overlaps are reported with the cue ID. For recorded voice, write content/cues.json as a list with id, start, speech_end, end, text, caption and relative wav. One timeline drives the drawing, English captions and sound.

Export a default object from src/film.mjs with duration, sheets and optional sounds. Each sheet is {at, seed, camera, draw}; add peel in seconds to enter on a folded page. All event and camera times are absolute film seconds. Camera keys are [seconds, centreX, centreY, zoom, optional easing]. The standard wide view is [time,960,540,1]. Easing can be 'in', 'out' or 'linear'; the default eases both ends. A hard match cut occurs at the incoming sheet's at. Pre-draw the shared incoming mark just before at. Mark an approaching push in sounds with {t,d,type:'push'}.

Inside draw, destructure the tools you need. Use E(start,end,'line'|'write'|'hatch'|'dash', marks). Marks are one mark or an array. T(text,x,baselineY,{size,color,weight,align,rot}) creates marker lettering; parts([[text,colour],...],x,y,{size}) lays out mixed ink. page(number,time) draws the circled folio. Geometry tools include line(x0,y0,x1,y1,o), circle(cx,cy,r,o), arc(cx,cy,r,startRadians,endRadians,o), poly(points,o), curve(points,o), rect(x,y,w,h,o), arrow and arrow2(x0,y0,x1,y1,o), dashed(points,o) and hatch(convexPolygon,o). Set w, color ('black', 'blue', 'red'), jitter or bow in o; circle/arc accept ry for an ellipse. For a match-cut mark, draw its master path at the origin once with a fixed seed, then use placeStroke(master,x,y,scale) on both sheets. Keep scale times camera zoom equal. This preserves polygon resolution, nib width and the darker touchdown across the cut. The renderer calls draw three times with deterministic seeds. Generate new silhouettes directly from geometric points, and keep random choices repeatable. Coordinates use a 1920 × 1080 sheet. Put small Latin superscripts or a hand-built mathematical glyph into the same line if the font lacks it. Drawing helpers return geometry; schedule it with E.

For recorded music, copy content/music.example.json to content/music.json. In Google Gemini’s Create music, choose Instrumental and request a sparse arrangement that fits this film’s pace, with a complete final phrase. Save the submitted prompt, original download, title and generation receipt in audio/gemini/. Decode its audio to a lossless WAV or FLAC with `python scripts/ffmpeg_serial.py -- -i audio/gemini/original.mp4 -map 0:a:0 -c:a flac audio/gemini/performance.flac`, substituting the downloaded filename if needed. Set source to that file’s project-relative path and source_sha256 to its SHA-256. Each cue gives film_in, film_out, source_in, fade_in and fade_out in seconds. Put any excision under the page turn and time the last cadence to the final hold. The retained recording rebuilds offline.

Keep continuous nib movement quiet under dialogue. As starting points, use music_under_voice_db of −20, marker_under_voice_db of −32 and speech_duck_db of 3.5. The mixer joins close marks, rounds their attacks and renders the page separately. Check the start of dense lettering and hatching as well as the fold. audio/mix-levels.json records measured stem levels during speech. The stereo narration, score, marker, paper and combined effects are exported alongside the final mix.

The blank kit also supports an authored content/score.json when a note chart is chosen. Notes use [startSeconds,instrument,midiPitch,durationSeconds,gain,optionalPan]. Instruments include bass, clarinet, bassoon, harp, bell, shaker, claves and block. rests is a list of [start,end] intervals. A supplied content/music.json selects the recorded performance.

Run `npm run events`, then `python scripts/sound.py`. Preview a composition at a given time with `npm run still -- 8 media/preview.jpg`. Run `npm run frames` and `npm run encode -- media/film.mp4`. For a changed interval, `npm run frames -- FIRST END` replaces it using half-open frame bounds. The encoder waits for any active FFmpeg processes. The final picture is 1920 × 1080 at 24 fps. Retain media/English.srt, the WAV stems, music source, timing edits and scene.

For a reference review, scripts/compare_frames.py scan MOVIE DIRECTORY decodes every presentation frame and retains a thumbnail tile and measurements. Run pair REF_SCAN FILM_SCAN ROLES.json OUT for both directions. List role objects with role, reference and output; endpoints are zero-based half-open frames and cover both films in order. Review the actual encoded layouts and the moving cut in addition to these numbers. For an independent skill-only production, seal the first encode before opening comparison material.
