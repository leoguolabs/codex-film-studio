# Working copy

Use the local style guide to author a new place portrait. Keep the original source material, license trail, original composition, English takes and shot decisions in the working copy. scripts/ffmpeg_serial.py serializes FFmpeg commands. The fonts/ directory includes the corresponding licenses.

Install requirements.txt in a Python environment. Import scripts/print_look.py from the film composition; cover fits a camera plate, Print.grade applies the print stock, split and grid compose real moving sources, day_ring places the day hand, and Print.matte places the theatrical aperture last. For calibration, run python scripts/render.py input.jpg proof.jpg. Author a separate shot list, source decoder and score suited to the production. Use a stereo PCM master and a serialized H.264/AAC delivery encode. Record source windows so the cut can be reopened and changed.

For variable-rate or legacy camera media, select exposures by presentation timestamp. Some WebMs report a 1,000 Hz time base as a frame rate. Inspect the clock, focus pulls and inside-source cuts on decoded footage. A number that continues over an edit must still describe the new shot. Compare the AAC master’s decoded true peak after muxing; a clean PCM peak can conceal an overshoot in the opening AAC window.

For exhaustive comparisons, use the shared decoded-frame audit or a frame CSV with luma, saturation, bright_area, dark_area, edge_density, texture and frame_delta columns in normalized units. Pass two frame CSVs and two JSON range lists to scripts/compare_roles.py in the order shown by --help. Each list contains [inclusive start frame, exclusive end frame, shared semantic role]. Both resulting tables preserve every input frame. The phase correspondence and the feature match let a reviewer inspect timing and appearance separately.

For an editable base picture use content/cut.json. Set assets to a mapping of names to source records. Each record takes file, optional in/out seconds for a moving source and still=true for a photo. Each shot takes an integer frames and a type of clip, still, split, grid, flicker or black. A simple shot uses asset, in (absolute source seconds), speed, and optionally center and zoom. A changing zoom takes two endpoint scales and a frame count. Composite shots use plates containing the same source-window fields. A grid supplies grid=[columns,rows]. Flicker uses hold in frames. phase=[start,end] draws the optional day ring in turns. Set audio to the relative path of the mixed master. Run python scripts/assemble.py content/cut.json media/film.mp4. This builds real-PTS source caches and writes a new MP4 only after a successful encode. Author staggered cell entrances, location-specific lettering, tracked light or documentary page lighting in the production composition when the story calls for them.
