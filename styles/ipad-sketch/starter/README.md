# Working with the tablet sketch page

Run `npm ci` and `npm run proof`. The proof writes `media/proof.jpg`. Install the Python requirements for sound. Place the audio clock in `content/narration.json` with `duration` in seconds and `lines` containing a unique `id`, English `text`, optional spoken spelling `speak`, caption `side` and relative pause weight `gap`. Set `lead`, `tail`, `speed` and `voice` as appropriate. Record with `python scripts/voice.py --models /path/to/kokoro`. Running without that flag rebuilds cue timing from the retained WAVs. Imported recordings may also supply the same cues and WAV paths.

In `src/film.mjs`, export `{duration,build(page,cues)}`. The duration must match narration. The build function authors marks in page units and seconds, then returns `{camera,accents,overlays,hideStylus}`. Only camera keys are required. Each key is `[time,x,y,zoom,degrees,move]`. Supply at least two strictly increasing keys. The last argument controls arrival at the key. Use `g` for a quick finger gesture, `i` for an accelerating push, `p` for a punch and `d` for drift. Let a completed stroke be read while starting the next detail nearby. Align meaning-bearing changes to recorded cue times. Opening and ending gestures should differ in scale.

The page exposes these drawing tools.

- `PEN(points,{w,p,layer,ta,tb,wob,smooth},start,duration)` draws a pressure-tapered graphite spline. Layer is `graph`, `light` or `coral`. Typical weight is 2–4 units. Use `smooth:false` on oversampled paths.
- `BLOB(polygon,color,{dx,dy,a,amp,holes,cuts,ang,sp,stop,replace},start,duration)` reveals a multiply block under the lines. Polygons are arrays of point pairs. `holes` and `cuts` take arrays of polygons. `stop` is a fraction. `replace:true` changes an existing state. Set `ghost:true` when a simultaneous secondary block should leave the stylus with the primary stroke.
- `OCC(polygon,time)` clears completed ink and colour inside the outline of a foreground object. `TXT(text,x,baselineY,size,{f,rot,layer},start,duration)` writes a short note. Fonts are `CB` and `CM`, rotation is radians. The other drawing calls accept seconds. Reserve space for the complete rendered word.
- `ell(cx,cy,rx,ry,rotation=0,startAngle=0,endAngle=2π,n=64)`, `bez(a,b,c,d,n)`, `spline(points,step)`, `circleStroke(cx,cy,r,options,start,duration)` and `arrow(points,options,start,duration)` provide geometry. A wash needs a closed region. A circle can carry an open highlight or reveal a small internal study.
- An overlay is `{start,end,draw(ctx,t,camera,page)}`. It receives a screen-space canvas context. Use `page.toScreen(camera,x,y)` to attach an effect to the sheet. After an effect, leave its result in the page drawing. `hideStylus` takes intervals `[[start,end],...]` when the pencil is off the glass.
- Accent events take `{t,type,pan,gain}` and support `tick`, `pop`, `rush` and `chime`. Pencil, write, fill and camera sounds come from the marks. Render `audio/score.wav` from an original arrangement. Keep its source, instruments, credits and music-only audio. The optional `python scripts/score.py path/to/soundfont.sf2` plays your own `content/score.json` with FluidSynth. Supply bpm, a voicings object mapping chord names to MIDI pitches (bass note first), and sections with a starting bar and a chord-name array. Optional section keys guitar (beat positions), bass, shaker and level control orchestration. Use mallet pairs [second, MIDI pitch] and rests [start, end] to score specific gestures. Then run `npm run events` and `python scripts/sound.py`.

Use `npm run still -- 12 /absolute/path/frame.jpg` for a still. `npm run frames` produces the full editable frame sequence. An optional half-open range takes integer frame numbers, e.g. `npm run frames -- 0 48`. After changing a mark, render from its first changed frame through any later view that still shows it. `npm run encode -- media/film.mp4` waits for any active FFmpeg job, then encodes the finished picture and mix. Keep the score, takes, cues, page code and final mix for rebuild.

For encoded comparison, install NumPy, Pillow and OpenCV. Run `python scripts/compare_frames.py scan film.mp4 review/this-film` for every presentation frame. For two scanned films, supply a JSON object with reference and film arrays of [startSeconds, shotRole] pairs, each beginning at zero. Run `python scripts/compare_frames.py compare reference-audit film-audit roles.json pairs` to save forward and reverse mappings. Inspect actual frames for high residuals and the intended action.

## Scoring an existing cut with a recorded performance

In Google Gemini, choose Create music, the long or standard length, and Instrumental. Describe the film, instruments, emotional turns, space for narration and ending. Save the original generated audio or the generated player movie, its prompt and credit. Decode the selected audio track once to a local FLAC, using the serialized FFmpeg wrapper for the conversion.

Set `content/music-edit.json` with `source` (the FLAC path relative to the project), `source_sha256`, `clips`, `solo_lufs`, `bed_gain_db`, `speech_duck_db`, `centre_presence_cut`, `mix_lufs` and `film_gain_db`. Each clip specifies `source_in`, `film_in`, `duration`, `fade_in` and `fade_out` in seconds. Gain automation consists of increasing [film second, gain in dB] pairs. The centre presence cut is a fraction between zero and one. Select levels and edits for the recorded performance and picture.

With the approved narration and pencil stems in `audio/`, run `python scripts/recorded_score.py`. This rebuilds `audio/score.wav` for a full-level music audition and `audio/mix.wav` for the film, both in stereo at 48 kHz. After changing voice cues or pencil actions, run `python scripts/sound.py` to refresh the stems and include the recorded performance. With an approved picture edit, copy the existing video stream when muxing the new mix. Verify the encoded music, narration, key contact, ending and picture packet sequence.
