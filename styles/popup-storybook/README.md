# Pop-Up Storybook

Start a production with `python3 scripts/new_film.py NAME --style popup-storybook`. The starter contains the camera, hinged paper cards, printed stage generator, score sampler and final encoder. Supply your own illustrated art, score and scene order. Instructions are in the [starter](starter/README.md).
