# Line Cutaway

A millimetre-based OpenGL engineering drawing on a warm gridded sheet. Start with the style guide and the editable empty kit in starter. The renderer supplies depth-tested surfaces, automatic silhouette and crease ink, world-space anchors, plotted labels and a serialized delivery encode.
