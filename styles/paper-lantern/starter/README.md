# Make a paper lightbox

Copy the kit to your production. Run `npm ci`. Install the pinned Python requirements with Python 3.11–3.13 in a virtual environment. Use `npx playwright-core install chromium` to install a dedicated offline rendering runtime, or point LIGHTBOX_CHROMIUM at a Chromium-for-Testing executable. The GPU compiler opens a local canvas in an isolated headless process. No online browser session is involved. Run `npm run proof` for a material swatch.

Define an ordered array of shots in src/film.js. Each entry has start (seconds), dissolve (incoming overlap in seconds, default 0.6) and make(), returning {S,update(localSeconds,filmSeconds)}. Create S with box(), add cut sheets once, and set their positions, emissive power and camera in update(). A shot can return {grade:{fade,expo,lift,gain},post:{aper,...}}. Shot updates must give the same scene for the same time. The outgoing shot continues during an overlap.

Import the drawing API from ../engine/box.js. Plate coordinates and camera values are millimetres. Y points up. A plate's drawing origin is its centre. Pass plate(S,{w,h,x,y,z,ink,trans,draw(c),windows(c)}) a Canvas2D drawing function. Standard grey stock is set before draw. windows(c) paints white emission on black and should coincide with an opaque pane in draw. The ink tint multiplies the physical stock. Typical z positions move from –128 mm in back to –30 mm in front. At d=340 a 26° camera covers about 344 mm at z=–80. The upper and lower visible limits are roughly +98 and –98 at that plane. camera(S,t,{x,y,d,lookX,lookY,focusZ}) sets the focus. power(mesh,k) drives the light. hole(c,fn), line(c,points,width), polygon(c,points), disc(c,x,y,r), label(c,text,x,y,mm,color,weight), lunar(S,opts) and move(mesh,x,y) are available. Rotations use radians. Give large travelling plates sufficient margins.

In timeline.json set title, duration and voice:[{at,text,caption?,hold?}]. Optional vertical bars in caption break the English caption into two lines. Default narration uses Kokoro bm_george. Place Kokoro 1.0 ONNX and voices-v1.0.bin in KOKORO_MODELS or ~/.cache/lightbox-voice. A retained take can be reused without the models. For external recordings place them at the paths computed by scripts/sound.py or author an equivalent timeline and stereo mix.

Compose notes as [time,instrument,MIDI pitch,duration,gain,pan]. Supported instruments are harp, glass, air, bow and bell. A sparse harp might use gain .03 and a bowed chord voice .015. Pan is optional between –1 and 1. Effects use [time,kind,duration,gain,optional pitch] with water, wind, paper, tap, bell, glass or harp. Set silence to [[start,end]] if the edit calls for a dark rest. Run `python scripts/sound.py` for timed captions, accepted voice WAVs, score, Foley and mix. Check the line endings and the action accents. Author more detailed sound when needed.

Run `npm run still -- 5 study.jpg`, then `npm run build`. Delivery defaults to 1920×1080 at 30 fps. SSAA=2 increases the GPU target resolution. RENDER_WIDTH supports smaller working proofs. All FFmpeg jobs pass through the shared serialization script, which checks live processes before launch. Keep the editable sources, timeline and accepted recordings alongside the MP4.


For a streaming master run `python scripts/master.py` after mixing and before the final build. It measures the stereo programme, retains its premaster and targets −14 LUFS with true-peak headroom. Check the encoded programme again. Small openings should retain warm detail while the surrounding card stays cool; compare the middle and dark values as well as the bright points. In a tracking shot, draw an identifiable near object large enough to truly pass across the action.

To use recorded instruments, provide audio/instruments/map.json, mapping an instrument name (for example harp, air or bow) to a list of objects with pitch (the recording's MIDI number) and file (a relative WAV filename). The renderer chooses the closest recording, retunes it to the score and applies the written duration. Keep the original samples and credits with the project.
