# Paper Lightbox
The independent WebGL starter builds a shallow illuminated paper theatre from authored silhouettes. Follow STYLE.md for direction and the starter README for the millimetre drawing API, timed recording, score and exports. The starter contains an empty film and a geometric material proof.
