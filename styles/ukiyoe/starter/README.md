# Make a mounted woodblock film
Install Node 20+ and FFmpeg, then run `npm ci`. All visual geometry uses a 1920 × 1080 sheet. The engine supplies stock paper, plate offsets, pressure marks, ink wipe, typography, a shared scroll, and a 24 fps camera. Read STYLE.md.

Author `film.js` as an ES module exporting `film={title,subtitle,seal,sheets}`. Set seal to a one- or two-letter maker's mark. Each sheet has a short English name (roughly 3–7 letters for vertical lettering), seconds, side ("left" or "right"), and an array of layers. For each layer use `{g,draw(ctx)}`. Paint in stacking order. Use g 0 for carved key lines, 1 for sky and blue, 2 for land or structures, and 3 for accents. Texture strengths can be edited via grain, baren and speck per layer. Set outlines in their own final layer when form permits. Each draw receives a regular Canvas 2D context. Call utilities from engine/print.js (PAL, bokashi, carve, fillPath, poly, kasumi) and engine/nature.js (pine, rock, rain, goose). Inspect their function signatures when authoring. Shapes and figures unique to the subject belong in your film.js or its imports.

Optional sheet callbacks receive (ctx,localSeconds,shotSeconds). motion runs inside the border at 8 fps, weather at 12 fps, and escape draws beyond the picture after the border. camera(localSeconds,shotSeconds) may return {x,y,zoom} relative to the sheet center. Use escape and camera for the climax. A sheet with reprint:true begins on bare paper and rebuilds by block. The first sheet already prints itself. The black impression is extracted from the final static color boundaries. Use cartoucheAt (local seconds) to place the late title stamp on a particular beat. The camera reads from the rightmost print toward the left end of the roll. The last seven seconds are reserved for the scroll ending. Set representAt (local seconds) to choose the pose in the final miniature. Set slide on an outgoing sheet to tune its transition duration.

Place a full-length stereo master at media/mix.wav. Put ordered English phrases in content/cues.json as objects with start, end (seconds) and text. New voice, score and foley should share these timings. Keep short phrases readable in the original-sized slip.

`npm run stills` makes a proof of each sheet. Use `npm run stills -- --times 2,12.5,33` for other instants. Use `npm run build -- --start 48 --end 168 --out media/test.mp4` for a motion excerpt. Build the release with `npm run build`. FFmpeg passes through ffmpeg_serial.py. The default output is media/film.mp4. Retain the WAVs and shot sources so the film re-renders offline.

For a detailed cast or a generated score, follow [the code-drawn performance and music workflow](PERFORMANCE-AND-MUSIC.md). The optional film or sheet settings motionFps and weatherFps control the sampling rate independently of the 24 fps camera. A film can set slide in seconds as the default scroll duration. Use cameraThrough from engine/lib.js with camera keys in [seconds, zoom, x, y] form for a deliberate move towards an action.
